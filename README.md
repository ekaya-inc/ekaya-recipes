# Ekaya Recipes

A Recipe is an end-to-end walkthrough of a real business use case with Ekaya. Each Recipe gives you two things: a video walkthrough to watch, and a prompt to paste that sets up Ekaya for that use case.

## Recipes

| Recipe | What it covers | Status |
| --- | --- | --- |
| [Getting Started](getting-started/) | Creating a project and setting up Ekaya | Coming soon |

## Using a Recipe

1. Open a Recipe from the table above. Each Recipe has its own folder in this repository.
2. Watch the video walkthrough.
3. Copy the prompt from the Recipe page and paste it as the Recipe describes.
